# To build the project
./gradlew build

# To run the game
./gradlew run (game is set as default main)
or 
./gradlew game

# To run the map creator
./gradlew map

# To test the project
./gradlew test

# Trivia
The game runs on linux given that java-openjdk-21 is installed. 
The performance is not great and could be run with wine for improved performance.
